## 1. Problem Statement

Financial fraud is a critical challenge in electronic commerce. The objective of the IEEE-CIS Fraud Detection problem is to predict whether a given credit card transaction is fraudulent (`isFraud` = 1) or legitimate (`isFraud` = 0) based on a massive, highly anonymized, and heavily imbalanced dataset containing transaction amounts, card properties, digital identities, and high-dimensional engineered features (`V` and `C` columns).

The challenge lies in handling severe missingness, high cardinality, multi-collinearity, and extreme outliers without dropping vital fraud signals or introducing data leakage.

## 4. Pipeline Stages & Implementation Architecture

The preprocessing workflow is split into modular execution blocks:

1. **Data Cleaning & Missing Value Imputation**: Drops excessively sparse columns (>70% missing) using custom rules, applying mode, mean, or median based on distribution shape.
2. **Duplicate & Inconsistency Management**: Detects duplicate records via custom hashing algorithms and standardizes text strings, capitalization, and malformed email/browser categories.
3. **Categorical Encoding**: Dynamically applies Label Encoding (binary/high-cardinality) or One-Hot Encoding (nominal features ≤15 unique values) using pure dictionaries.
4. **Outlier Detection & Treatment**: Computes Interquartile Range (IQR) and Z-Scores from scratch. Implements a retention/winsorizing policy to preserve extreme fraud indicators.
5. **Feature Selection**: Evaluates features using custom Variance Thresholds, Pearson Correlation (collinearity), Chi-Square, ANOVA F-Test, and Mutual Information, actively pruning uninformative variables.
6. **Feature Scaling**: Applies Standardization ($\mu=0, \sigma=1$) from scratch across numerical features.

## 5. How to Run the Project

1. **Setup Environment**: Ensure Python and required libraries (`pandas`, `numpy`, `matplotlib`) are installed in your virtual environment.
2. **Load Data**: Open `pre_processing_pipelines.ipynb` inside Jupyter Notebook or VS Code.
3. **Execute Pipelines Sequentially**: Run the modular pipeline blocks cell-by-cell:
```python
from utils.categorical_pipeline import run_categorical_pipeline
from utils.outlier_pipeline import run_outlier_pipeline
from utils.scaling_pipeline import run_scaling_pipeline
from utils.feature_selection_pipeline import run_feature_selection_pipeline

# Execute orchestration workflows
train = run_categorical_pipeline(train)
train = run_outlier_pipeline(train)
train = run_feature_selection_pipeline(train, target_col='isFraud')
train = run_scaling_pipeline(train)

```
